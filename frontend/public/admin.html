Backup & restore

All data (products, images, settings, messages) is downloaded into a file. After a new computer or browser reset, you can restore it using the “Restore” option. It is good practice to take a backup once a week.

Admin login is verified on the server. The password is not stored in the browser. Run the live site on HTTPS with a persistent disk-backed Node.js host. Do not forget to keep a separate backup of the website data.
